# Finance Tracker 💸

A Java-based personal finance management application designed to track accounts, transactions, budgets and financial statistics.

## Current Features

* Account management
* Multiple account types
* Multiple currencies
* Income and expense transactions
* Transaction categories
* Account balance management

## Planned Features

* Budget management
* Account-to-account transfers
* Custom exception handling
* Financial statistics using Java Streams
* JUnit testing
* PostgreSQL database
* Spring Boot REST API
* Docker
* GitHub Actions CI/CD
* Kubernetes deployment

## Technologies

* Java
* Git
* GitHub
* JUnit
* PostgreSQL
* Spring Boot
* Docker
* GitHub Actions
* Kubernetes

## Project Goal

The project is being developed as a practical Java and Cloud/DevOps project, focusing on object-oriented programming, clean architecture, testing, backend development and cloud-native technologies.
